# Digital House

Интернет-магазин цифровых товаров. Лабораторная работа №2 по дисциплине «Интерфейсы информационных систем».

Проект на React + Vite. Реализованы компоненты `Button`, `ProductCard` и `QuantitySelector`. Данные в карточку передаются через props, количество товара хранится в локальном состоянии `useState`.

## Требования

- Node.js 18 или новее
- npm

## Запуск

```bash
npm install
npm run dev
```
